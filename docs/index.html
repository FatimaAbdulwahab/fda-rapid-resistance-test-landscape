FDA-cleared rapid resistance test landscape

What each FDA-cleared or De Novo-authorized rapid blood culture identification/resistance panel and rapid phenotypic susceptibility system detects, and what its own FDA document says a negative result does and does not rule out. Every row traces to a 510(k) or De Novo number and page.

This is a regulatory-labeling reference, not a performance comparison. It does not say which test is better, and labeling of later submissions may differ from the source document cited. Check the current package insert before acting on any entry.
